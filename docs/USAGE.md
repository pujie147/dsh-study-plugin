# 使用手册（学习区 study-work）

本手册面向使用者。学习区帮你管理多个「学习目标」：每个目标由会话 AI 联网调研产出课程草案，你批准后按自然章节生成讲义，每章在**独立会话**中学习与多轮问答。

## 1. 入口

左侧栏底部有 **「📚 学习区」** 徽标（侧栏收起时是圆形 📚 图标），点击展开浮动面板；徽标上的数字 = 正在调研/待批准/学习中的目标数。面板 2.5 秒自动刷新。

## 2. 面板操作

| 按钮 | 作用 |
| --- | --- |
| ＋ 添加学习目标 | 填写 主题 / 目标水平 / 附加要求 → **「✓ 创建并调研」**：先建文档，自动打开该目标专属会话，会话 AI 联网调研（5–10 章草案，按自然结构，不按学时）。完成后自动变为「待批准」 |
| 📄 打开会话 | 切换到该目标的**总会话**（首次打开后会话才可接收调研/讲义任务） |
| ✓ 批准 | 批准草案 → 章节清单生成（每章状态「待生成」） |
| 重新调研 | 退回草案并清空旧草案文件，回到「调研中」 |
| 生成讲义 | 向目标总会话发送该章讲义撰写任务；文件写好后自动「讲义就绪」 |
| 继续生成 | 讲义停在「生成中」且文件未产出时点击：若文件其实已生成会直接标记就绪；否则重发任务。若会话未在工作，会退回「待生成」并提示你先打开目标会话再点「生成讲义」 |
| 📖 开始学习 | 为该章**创建独立章节会话**并进入（每章一个，已建过则直接打开） |
| 删除 | 仅标记删除（数据文件保留） |

## 3. 会话模型（怎么学）

1. **目标总会话**：负责调研与讲义生成，别在这里学习。想改课程草案时在这里让 AI 直接重写 `draft.json`。
2. **章节会话**：点「开始学习」进入后，AI 以本章讲义开场（读讲义 → 目标与要点概览 → 等你提问，逐点讲解）。每次回答后，如果 AI 发现回答中有讲义未覆盖的有价值补充内容（新示例、新角度、易错点、实战技巧等），会询问你是否要回写——回复「回写」即可。回写采用**「总结入讲义 + 详细独立文件」**模式：讲义中只插入一行带链接的总结（如 `> 💡 [补充：xxx](NN-notes/slug.md) — 核心要点`），详细内容存放在 `chapters/NN-notes/` 目录下的独立文件中；同一主题多次回写会在同一文件中累积扩展。你说「结束」时它总结本章并把问答要点写入 `NN-qa.md`。多轮问答沉淀在学习内容里，可随时再进该会话继续问。
3. **主聊天**：管理进度/目标（见 §4）。学习本身在目标/章节会话里发生。

> 设计上无测验、错题本与「已学完」标记：学完一章后仍显示「讲义就绪」，随时可重学。

## 4. 聊天里直接管理

直接输入自然语言即可，例如：

- 「看看我的学习进度 / 学到哪了」→ 各目标进度与下一步建议
- 「帮我建一个学 XX 的计划（目标：能…；要求：中文讲义）」→ 建目标；随后按提示打开一次目标会话，再说「开始调研」
- 「开始调研 / 重新调研」→ 在目标会话内发起/重发联网调研
- 「草案可以，批准」/「草案不行，改成 XX」→ 批准或退回

## 6. 重启之后怎么办（恢复）

DSH 进程重启后，动态插件会丢失，但**所有学习数据、工作区与目标/章节会话都保留**：

1. 重开 GUI（本会话或其他会话），对助手说：**「按 C:\Users\pyg12\.dsh\study-work\plugin\INSTALL.txt 恢复学习插件」**；
2. 助手读取快照 `study-plugin.dist.json`，重新定义并激活插件（客户端需在 GUI 点一次批准）；
3. 学习区入口恢复，旧目标直接出现在列表中，点「打开会话」可继续之前的学习。

也可让助手直接从项目仓库重装：`C:\Users\pyg12\gitProjects\study_dsh_plugin`（见该仓库 INSTALL.md）。

## 7. FAQ

- **章节一直「生成中」**：点「继续生成」；若提示先打开会话，就点该目标的「📄 打开会话」后再继续。
- **「重新调研」后还是旧草案**：新版退回会清空草案文件，不会复现旧草案；如仍显示，点 ⟳ 刷新。
- **批准后想改课程**：退回草案 → 在目标会话里让 AI 修改并重写 `draft.json` → 重新批准。旧讲义文件不会被自动删除。
- **删除目标会不会删文件**：不会，仅移出列表并标记 deleted。
- **「打开会话」没反应**：先确认已点过面板 ⟳；若报错请把面板红字发给我。
- **测验/错题/复习入口在哪**：已按需求移除，学习闭环 = 讲义 → 独立会话教学与多轮问答 → 写回 NN-qa.md。
